# Courier Newsroom — Code Samples

Selected files from a WordPress VIP multisite network of 21 regional
news publications, extracted from a private client repository.

The platform was architected by Alley Interactive. These are features
I built into it, following the established patterns of the codebase.
Site identifiers, credentials, and configuration values have been
removed.

Each directory has its own notes on the problem, the approach, and
the tradeoffs.
